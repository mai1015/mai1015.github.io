HELIX land maps

Tooling that rendered a map image for every parcel in the HELIX land collection.

  • A React and TypeScript view places each parcel on a styled 3D city map with its address, area and tier.

Open source · Public beta

Forge

A local-first workflow engine for coding agents, written in Rust.

  • Runs each agent task through a lifecycle of todo, in progress, review, merging and done, with an audit log and cancellation paths.
  • Gives every task its own isolated git worktree, and blocks merge until the task's CI steps pass review.
  • Ships a REST API, an MCP endpoint, a CLI and a React web UI in one binary, with SQLite persistence.

Rust · SQLite · REST · MCP · React
